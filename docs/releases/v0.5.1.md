## Better Blender v0.5.1

The first packaged GitHub release includes the MCP server and its matching Blender add-on.

### Install

Follow the [release installation guide](https://github.com/JonathanGrocott/better-blender/blob/v0.5.1/docs/installing-releases.md).

Download the **`.whl`** below for the MCP server. It also includes the add-on, installable with `better-blender-mcp install-addon`. The **`better_blender_bridge-0.5.1.zip`** is an alternative for manual installation in Blender. The automatically generated **Source code** archives are for developers.

Requires Python 3.11+ and Blender 3.4.1+. Blender integration is tested with 3.4.1, 4.2.0 and 5.0.1 on Linux; Python/package checks also run on Windows and macOS.

### Included

- Scene, object, animation, material, geometry-node and rendering tools.
- Document guards, durable request IDs and outcome lookup for safe retries.
- Generated credentials, read-only mode and optional tool-path restrictions.
- Recovery checkpoints, retention limits, external asset checks and diagnostics.
- Supervised render jobs with a configurable one-hour default deadline, cancellation and crash cleanup.
- Startup rollback and complete shutdown of database/logging resources.

### Upgrading from a checkout or Actions build

Install the wheel, reinstall the matching add-on, then restart Blender and your MCP server. Leave the add-on token override blank to use the generated credential. Remove an old explicit `change-me` value from your MCP configuration; existing custom tokens remain supported.

Distributions are unsigned. `SHA256SUMS` contains hashes for both files so downloads can be checked for corruption. Publishing a GitHub Release does not publish the package to PyPI.
